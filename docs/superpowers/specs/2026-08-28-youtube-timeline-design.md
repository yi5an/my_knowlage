# YouTube 历史时间轴设计

## 1. 目标

将 YouTube 历史总结从“最新 50 条列表”升级为可长期浏览的博主泳道时间轴。所有采集记录都可按 YouTube 原始发布时间回顾，成功、失败和处理中状态保持可见，并支持按博主和年月快速定位。

## 2. 已确认的用户体验

- 默认所有博主按时间范围混排，但以博主为横向泳道展示。
- 默认显示最近活跃的 6 位博主；点击“显示全部博主”后可横向滚动查看其余泳道。
- 泳道按最近发布/最近活跃时间降序排列。
- 每张卡片显示缩略图、标题、博主、发布时间、状态、两行 AI 摘要和标签。
- 成功、失败、处理中、无字幕和无访问权限记录均展示。
- 失败卡片保留“重新处理”按钮；无访问权限卡片不提供重试。
- 日期列和泳道标题在滚动时固定；向下滚动加载更早历史。
- 顶部提供年份/月选择器，用于跳转到指定时间段；跳转不改变已有任务状态。

## 3. 后端接口

新增 `GET /api/v1/youtube/timeline`，参数如下：

- `workspace_id`：工作区，默认 `ws_default`。
- `limit`：单页数量，设置合理上限（建议 100）。
- `cursor`：不透明游标，定位到下一页更早记录。
- `channel_id`：可选博主筛选。
- `status`：可选状态筛选，默认返回所有状态。
- `year_month`：可选 `YYYY-MM` 时间定位。

返回 `TimelinePage`：

- `items`：时间轴视频卡片；复用现有状态、摘要、标签和重试字段，并增加 `time_source`（`published_at` 或 `created_at`）。
- `next_cursor`：还有更早记录时返回，否则为 `null`。
- `channels`：当前工作区博主及其最近发布时间，供前端计算默认活跃 6 个泳道和“显示全部”。
- `months`：有记录的年月及数量，供年月导航显示。
- `total` 与 `status_counts`：总数和状态统计。

排序使用 `(effective_time DESC, video_id DESC)`，其中 `effective_time` 优先为 YouTube `published_at`，为空时回退 `created_at`。游标编码完整排序键，保证翻页不重复、不遗漏；时间相同的视频使用 `video_id` 作为稳定 tie-breaker。

现有 `GET /youtube/summaries` 保留兼容，详情页、订阅页和重试接口不改变。

## 4. 数据规则

- 缺少 YouTube 原始发布时间时使用平台创建时间，并在卡片显示“平台时间”。
- 缺少博主名称或频道 ID 的记录进入“未识别博主”泳道。
- `ignored_live` 不进入时间轴，继续保持直播/预约直播完全忽略。
- `access_denied` 进入时间轴但不可重试。
- `failed`、`no_transcript`、处理中状态进入时间轴；失败卡片展示脱敏后的错误摘要。
- 新任务状态通过刷新当前页更新，保持滚动位置，不重建整个时间轴。
- 历史记录不因视频被删除或失效而静默移除。

## 5. 前端实现

在 YouTube 历史页增加时间轴视图：

1. 首次请求时间轴第一页，建立最近活跃 6 个泳道。
2. 使用 Intersection Observer 或等价触底检测加载 `next_cursor`，合并到现有泳道，不重复视频。
3. “显示全部博主”切换到横向滚动容器；日期列保持 sticky，泳道标题保持 sticky top。
4. 博主筛选和状态筛选重新请求第一页；年月选择使用 `year_month` 请求定位页。
5. 卡片点击行为保持现有约定：已完成进入总结详情，处理中/失败打开状态信息；失败卡片调用现有 `POST /youtube/videos/{video_id}/retry`。
6. 桌面端采用横向泳道；移动端保留日期列并允许水平滚动，卡片宽度固定在可读范围。

为了兼容当前页面，时间轴可以作为“历史总结”的默认视图；不改变顶部手动提交、订阅管理和详情页入口。

## 6. 错误处理

- 游标非法或过期返回 400，并提示前端重新从第一页加载。
- 不存在的工作区沿用现有默认工作区行为。
- 后端查询失败时返回统一 API 错误结构，前端保留已经显示的内容并提供重试。
- 单个卡片字段异常不应阻塞整页；使用字段级回退（标题回退 video_id，日期回退 created_at）。
- 加载下一页失败只影响该页加载，不清空已有时间轴。

## 7. 测试与验收标准

### 后端

- 时间按 `published_at` 降序，缺失时正确回退 `created_at`。
- 相同时间使用 `video_id` 稳定排序；连续游标翻页无重复、无遗漏。
- 博主、状态和年月参数组合过滤正确。
- 成功、失败、处理中、无字幕和无访问权限状态均返回；直播记录排除。
- 返回博主活跃排序、月份统计和状态统计正确。
- 非法游标、空结果和部分缺失字段有明确响应。

### 前端

- 默认只呈现最近活跃 6 个博主泳道，并能展开全部。
- 横向滚动时日期列/泳道标题固定，卡片可读。
- 触底加载更早历史，加载失败不丢失当前内容。
- 年月跳转、博主筛选和状态筛选能重置游标并正确展示结果。
- 各状态卡片样式、失败重试按钮和详情跳转符合现有行为。

### 回归

- YouTube 手动总结、历史列表兼容接口、订阅管理、视频详情和 AI 陪读入口继续可用。
- 不修改直播忽略策略、Cookie 管理和现有转写重试队列。

## 8. 非目标

- 本期不改变视频采集、转写、总结或 ASR 算法。
- 本期不删除或迁移已有 Video/Document 数据。
- 本期不将时间轴扩展到投资信息或普通文档；仅覆盖 YouTube 历史。
